# 🌌 Planet Explorer

Planet Explorer adalah website edukasi yang membahas tata surya dengan cara yang sederhana, menarik, dan mudah dipahami.

Website ini dibuat sebagai proyek Pemrograman Web untuk membantu pelajar mengenal planet, Matahari, benda langit, dan berbagai fenomena dalam tata surya.

## ✨ Fitur

- Informasi mengenai tata surya.
- Pengenalan Matahari dan delapan planet.
- Informasi benda langit dan fenomena tata surya.
- Fakta menarik tentang luar angkasa.
- Kuis interaktif untuk menguji pengetahuan pengguna.

## 🛠️ Teknologi

- HTML
- CSS
- JavaScript

## 🚀 Cara Menjalankan

1. Download atau clone repository ini.
2. Buka folder proyek.
3. Jalankan file `index.html` melalui browser.
